# Mini CRM 🚀

Mini CRM is a modern full-stack CRM web application built using the MERN stack.

## ✨ Features

- JWT Authentication
- Lead Management
- Dashboard Analytics
- Pie & Bar Charts
- Dark Mode UI
- Protected Routes
- CSV Export
- MongoDB Atlas Integration
- Responsive Design

## 🛠️ Tech Stack

Frontend:
- React.js
- Tailwind CSS
- Vite

Backend:
- Node.js
- Express.js
- MongoDB
